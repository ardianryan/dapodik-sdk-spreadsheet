# Panduan Kontribusi

Terima kasih atas minat Anda berkontribusi pada **`dapodik-sdk-spreadsheet`**!

## 🌿 Kontribusi
1. Fork repositori ini.
2. Buat branch baru (`git checkout -b feat/peningkatan-fitur`).
3. Commit perubahan Anda (`git commit -m 'feat: tambah fitur XYZ'`).
4. Push ke branch Anda (`git push origin feat/peningkatan-fitur`).
5. Buat Pull Request baru.
